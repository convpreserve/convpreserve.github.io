Testing Conversation Preservation Across LLM APIs

LLM API translators can silently drop instructions, alter tool contracts, inject reasoning or sampling controls, and corrupt streamed replies—even when translated payloads are schema-valid. ConvPreserve is a deterministic, rule-based test oracle that checks whether conversation meaning survives translation.

Getting Started

      Install from source and verify against the 574 bundled reference cases
    

    

      

        

          1. Install & run self-test
          
        

        
$ git clone https://github.com/convpreserve/conv-preserve.git
$ cd conv-preserve && pip install .
$ convpreserve selftest
400 identical / 400 total
rule cases: 174 identical / 174 total
PASS

      


      

        

          2. Check a pair or a JSONL manifest
          
        

        
$ convpreserve check --side request --src-dialect openai \
    --dst-dialect anthropic examples/quickstart/src.json \
    examples/quickstart/dst_thinking_injected.json
S08  T1  unlicensed control thinking injected  dst:/thinking

$ convpreserve batch examples/manifest.jsonl --out findings.jsonl
pairs=14 errors=0 T1=26 T2=5 T3=7 pairs_with_T1=14

      

    

  







  

    

      
Documentation

      CLI subcommands, severity tiers, and continuous integration hooks
    

    

      

        
          
SubcommandOptionsDescription

        
        
          
convpreserve check--side --src-dialect --dst-dialect [--json | --format github]Compare one source payload against its translated counterpart (- reads stdin).

          
convpreserve batchMANIFEST [--out FILE] [--summary-md FILE] [--fail-on TIER]Evaluate a JSONL manifest of pairs and aggregate counts by rule and dialect pair.

          
convpreserve probe--gateway URL --target {openai,responses,gemini,anthropic}Start a local loopback sink, send 51 Anthropic request shapes, and judge forwarded traffic.

          
convpreserve explainRULE | --list [--json]Print rule definition, tier, principle, and curated translator root causes (S03–S09).

          
convpreserve selftest[--oracle v1.0 | v1.3]Replay the 400-pair stratified sample and 174 per-rule unit cases.

          
convpreserve dialects—List canonical dialect identifiers and short CLI aliases (openai, responses, anthropic, gemini).

        
      

    


    

      

        

          
TierSemanticsDefault exit

          
            

              T1
              Silent semantic change to messages, roles, tool schemas/calls, controls, reasoning, or stop reasons (S01–S13).
              exit 1
            

            

              T2
              Declared capability loss, adapter-injected default where unset, or dropped cache/usage metadata (D01–D06).
              exit 01 with --fail-on T2
            

            

              T3
              Wire representation difference only; conversation semantics preserved (R01–R08).
              exit 01 with --fail-on T3
